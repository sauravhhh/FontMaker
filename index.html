Export your font

A real font file, made only from the letters you've drawn. Undrawn letters are left blank — draw at least A–Z to use it for everyday typing.

Install it: Windows — double-click the .TTF → Install. Mac — open in Font Book → Install. Android — use a font installer / zFont with the .TTF. iPhone — install via iFont or AnyFont, then pick it in apps that support custom fonts.

01 — DRAW

One letter at a time

Pick a letter on the left, trace over the faint ghost or go freehand. Pen, eraser, three brush sizes, undo and redo are all on the board.

02 — PREVIEW

See it as a font

As you draw, FontMaker rebuilds a working TTF in your browser and types your test sentence in it, so you can spot letters that need a fix.

03 — EXPORT

Take the file

Download the .TTF and install it anywhere. Save a project file too — open it here later to keep editing the same font, or start a second font alongside it.
